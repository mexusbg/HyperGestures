# Private framework resource IDs the build check lets through (Gradle task privateResIdCheck,
# `python -m tools.hgtools.private_res_ids --check`; docs/research/private-resource-ids.md).
#
# javac/kotlinc inline com.android.internal.R constants as the numbering of the firmware the
# framework stub came from (prebuilts/device). Every other private ID in the release dex fails the
# build; reachable code resolves its private framework resources by name (HgSysRes) instead.
# The check also fails when a listed name no longer has its listed ID in
# prebuilts/device/framework-res.apk, and `--compare <framework-res.apk>` checks the list against
# a new firmware before an OTA (runbook §9).
#
# Format: <0xID> | <type>/<name> | <dex|res> | <reason>
#   dex: a constant in the release dex (device ID)
#   res: linked into compiled resources by aapt2 from android.jar (SDK ID), allowlisted in
#        private-refs-allowlist.txt; acceptable only while the device ID equals it
